# 프로필·조회·계획 도구 변경 검증

## 구현한 범위

- 프로필: 레벨 → 닉네임 → 새로고침/즐겨찾기 → 서버 캐시 생성 시각 순서. 기본 프로필/실험체/매치 히스토리/스킨 통계 탭.
- 스킨 통계는 보유 목록이 아닌 관측된 사용 기록. 최근 페이지와 시즌 수집 결과의 범위를 구분한다.
- 새로고침은 실제 최근 전적 조회를 갱신한다. 5초 내 중복 요청은 공유한다. 실패 시 기존 전적 보존.
- 주력 실험체 이미지는 시즌 전체 스킨 스캔을 기다리지 않고 먼저 표시한다. 장비/특성 응답도 프로필 이미지 렌더링을 가로막지 않는다.
- 공통 검색 입력의 focus/focus-visible outline/box-shadow 제거. 다른 버튼/링크의 키보드 표시 유지.
- 기존 참가자 티어/RP 구현을 유지한다. 경기 시작 RP와 현재 RP 구간에 따른 티어이며, 당시 상위 랭킹 미제공으로 미스릴 이상을 구분하지 않는다.
- 공개 카탈로그에도 기존 Supabase 캐시를 사용해 재기동 후 스냅샷 재사용. 닉네임 30초 캐시 및 검색 후 최근 전적 선조회.
- 루트 시뮬레이터: 실험체 선택, 무기군/등급별 5부위 장비, 초반/후반 구성, 기본 장비 능력치 합계, 전술 스킬/핵심 특성, 재료 확보, 시작 지역 지정과 추천 방문 순서, 공유 링크 저장/복원.
- 야생동물 도구: 지역 대표 위치에 사냥 목표 표시, 시작 지역, 목표 수/이동 부담 설정, 크레딧 대비 비용 추천, 동물 필터, 개체 수/변이체 수정, 처치 및 지역 제외, 수동 동선/되돌리기/공유.

## 검증

- 기존 JS 16개 + 신규 계획 도구 테스트 1개: 로컬 17개 파일 통과.
- 739625c 첫 프로필 변경: GitHub Actions 34815111812에서 Java 테스트 및 bootWar/JS 성공.
- 최종 98044aa: GitHub Actions 34816956442와 34816938758에서 java/offline 성공. live job은 수동 실행 조건이 아니어서 skipped이며 운영 테스트 성공으로 간주하지 않는다.
- Java 17은 설치되어 있으나 로컬 Gradle 배포 다운로드가 네트워크 제한으로 실패. 로컬 Java 실행 성공으로 기록하지 않는다.
- Cloud Browser에서 localhost:8088 접근이 ERR_BLOCKED_BY_CLIENT로 실패. 신규 UI의 실제 브라우저 검증은 미완료.
- 공개 서비스 첫 HTML 요청 측정: HTTP 200, 약 12.719초. 애플리케이션 데이터 완료 시간과 별개이며 Render 중간 화면이 HTTP 200일 수 있다.
- 이후 운영 메인에서 Render `Service waking up` 및 `Application loading` 화면 직접 관측. 모든 메뉴의 정상 상태 속도/시각 검증 완료로 기록하지 않는다.
- Supabase EternalReturnGG 프로젝트 ACTIVE_HEALTHY. er_api_cache/er_match_archive RLS 활성화. 캐시 1,945행 및 경기 675행 관측. DB/Edge Function 변경 없음.
- Render 커넥터는 미선택 작업공간 오류. 목록에 NAKK가 있으나 도구가 사용자 확인을 요구하여 서비스 내부 조회/배포는 수행하지 않았다.

## 아직 완료되지 않은 사용자 요구

- **첫 조회부터 모든 메뉴 1초 미만:** 달성/측정 완료 아님. Render Free는 15분 무접속 후 정지하고 재기동 대기가 존재한다. 정상 상태에서 메뉴별 데이터·이미지 완료 시간도 별도 측정 필요.
- **닥지지와 동일한 야생동물 지도:** 현재 지역 단위 초안. 개체별 정확한 좌표/전체 스폰 수/변이체의 날짜별 배치/하이퍼루프/CCTV/크레딧 공유 범위 미구현. 화면에서 판독한 일반 캠프 예비 목록은 정식 스폰 데이터와 재대조 필요. 근거 없는 정밀 경로/시간을 표시하지 않는다.
- **닥지지 루트 시뮬레이터 전체 동등성:** 임의 루트 ID 가져오기, 실험체별 허용 무기 제한, 보조 특성 세트, 드론 호출 가격/크레딧 계산, 고유효과·레벨·숙련도 포함 능력치 계산, 후반 여러 빌드 세트는 남아 있다.
- 최근 갱신 버튼은 최근 전적을 강제 갱신하며 랭크는 기존 30초 캐시 정책. 전체 탭이 동시에 동일 시점으로 강제 갱신되는 기능은 별도 필요.
- 최종 변경의 모바일/데스크톱/다크 모드 시각 검증, 공유 복원 및 즐겨찾기 실제 조작, 모든 메뉴 회귀, 운영 배포 확인 미완료.
