# 내 화면 기반 지도 보조 — 실험 기능

## 제공 범위

- 야생동물 지도에서 화면 공유 버튼으로 사용자가 직접 게임 창/탭을 선택한다. 음성은 요청하지 않는다.
- 이미지 또는 MP4/WebM 파일도 로컬에서 열 수 있다. 업로드 API, 화면 저장, 게임 메모리/패킷 접근은 없다.
- 지도 영역을 드래그하고, 화면 지도와 사이트 지도에 지형 기준점 3쌍을 지정한다. 비공선 3점의 affine 변환으로 지도 좌표를 맞춘다.
- 사용자가 자기 아이콘 중심과 크기를 지정한다. 색상 패턴을 찾고, 서로 떨어진 두 후보가 비슷하면 결과를 거부한다. 두 프레임에서 위치가 이어질 때만 사냥 동선 출발점을 갱신한다.
- 지형 기준점의 화면 패턴이 바뀌면 지도가 움직였거나 가려진 것으로 보고 추적을 멈춘다. 자동 지형 매칭/이동 보정은 아니다. 전체 지도와 미니맵을 전환하거나 확대하면 다시 보정해야 한다.
- 분:초 영역을 OCR로 읽고, 확인 버튼을 누르면 선택한 일차/낮밤에 반영한다. 같은 구간에서만 자동 갱신 가능하다. 역행/큰 시간 점프/5초 이상 인식 간격/낮밤 수동 변경 때 재확인한다.
- 일차와 해/달 아이콘 자동 인식, 타이머가 없는 캠프의 실제 생존·처치는 자동 판정하지 않는다. `캠프 전체 처치 기록` 버튼으로 확인한 처치를 기록한다.
- 기존 시간표는 8일차 낮까지만 지원한다. 참고 영상의 9일차 화면은 알려진 범위 밖이다. 9일차 이후 시간표가 공식 자료로 확인되기 전 임의로 길이를 만들지 않는다.

## 사용 순서

1. `내 화면으로 위치 연결 · 실험 기능`을 연다.
2. 게임 화면을 공유하거나 이미지·영상 파일을 연다.
3. 지도 영역을 드래그한다. 설정을 위해 화면이 고정된다.
4. 화면 지형 → 아래 사냥 지도의 같은 지점 순서로 떨어진 기준점 3쌍을 클릭한다.
5. 공유 화면의 내 아이콘 중심을 클릭한다. 아이콘 크기는 미리보기의 내부 픽셀 기준이다.
6. 움직이는 공유 화면/영상은 `고정 해제` 후 `위치 추적 시작`을 누른다. 현재 위치를 출발점으로 추천 버튼을 사용할 수 있다.
7. 시간 숫자 영역만 드래그하고 `시간 읽기` → 일차/낮밤 확인 → `읽은 시간 적용` 순으로 진행한다. 자동 갱신은 고정을 해제한 움직이는 화면에서만 켜진다.
8. 공유 종료 또는 페이지 이탈 시 트랙과 작업자를 종료하고 미리보기를 지운다. 공유 링크에는 화면/보정/템플릿을 넣지 않는다.

## 검증 결과 (2026-09-16)

- `node --test src/test/js/*.test.cjs`: 20개 파일 통과.
- `NODE_PATH=/tmp/er-screen-test/node_modules node scripts/verify-screen-assist-dom.cjs`: 통과. jsdom 26.1.0 기반으로 브라우저 API를 모사한 DOM 테스트이며 실제 화면 공유 검증은 아니다.
- DOM 검증: 늦게 완료된 공유 허용의 트랙 정리, 3점 보정과 지도 클릭 전파 차단, 두 프레임 확인 후 위치 적용, OCR 명시적 확인, 구간 불일치, 고정 화면 자동 갱신 거부, 공유 종료/파일 실패/페이지 정리.
- 사용자 제공 첫 이미지의 숫자 영역: `01:31`, OCR 엔진 신뢰 점수 92. 두 번째 이미지: `00:11`, 점수 94. Tesseract.js 7.0.0 / 영문 fast 데이터 / 숫자와 콜론만 허용 / 흰색 글자 이진화 후 3배 확대.
- 두 이미지에서 지정한 아이콘 패턴을 같은 정지 프레임 내에서 다시 찾았다. 이는 자기 아이콘 구분이나 연속 이동 정확도의 검증이 아니다.
- 기하 변환, 일직선 보정점 거부, 이동한 합성 패턴 찾기, 중복 후보·미검출 거부, 시간 문자열/연속성 검사 통과.
- 기존 Playwright 스크립트에 새 스크립트 로드를 연결했다. Chromium 검증 스크립트는 canvas.captureStream으로 60초 이동 추적, 실제 번들 OCR, 지도 변경 중단, 트랙 종료를 검사한다. 실제 게임 창 캡처와 MP4/WebM 디코딩 검증은 별도다.

## 남은 실제 환경 검증

- Windows Chrome/Edge에서 게임 창 선택, 전체 화면 게임 캡처, 공유 종료, 화면 해상도 변경.
- 1분 이상의 실제 이동: 자기 초상화 변경, 아이콘 겹침, 금지구역·핑·지도 확대/이동으로 인한 추적 중단 및 재보정.
- 실제 게임과 인식 위치 비교 오차, 초당 처리량, 게임 프레임 영향. 엔진 신뢰 점수는 실제 정확도 백분율이 아니다.
- 날짜·낮밤 자동 판정과 최신 9일차 이후 시간표 검증, 시야 내 동물 인식은 후속 구현.

## 의존성과 출처

`static/vendor/tesseract-7`에 Tesseract.js 7.0.0, tesseract.js-core 7.0.0의 비 SIMD LSTM 빌드와 영문 fast 데이터를 동봉했다. OCR 버튼을 누를 때만 로드한다. 비 SIMD 단일 빌드는 다운로드 중복을 피하기 위한 선택이며 기기별 최적 빌드 자동 선택은 추후 개선 대상이다. 라이선스 파일을 함께 보존했다.

## 캠프 전체 처치 타이머 (2026-09-16 후속)

- 사용자 확인 규칙: 스폰 위치의 타이머는 무리 전체 처치 후 시작한다. 개체별 타이머가 아니다.
- 화면 설정에서 캠프를 선택하고 `⑤ 동물 타이머 숫자 영역`, `⑥ 동물 아이콘 중심`을 지정한다. 화면 고정을 해제하고 게임 시간을 읽어 적용한 뒤 시간 자동 갱신과 타이머 인식을 켠다. 현재 한 캠프씩 추적한다.
- 선택 아이콘 주변을 추적하여 카메라 이동에 따라 숫자 영역을 옮긴다. 아이콘이 사라지거나 비슷한 후보가 겹치면 중단한다. 큰 카메라 이동·확대·축소 후에는 다시 지정한다.
- `106s` 또는 `1:46` 형식을 3회 이상, 최소 2초의 감소로 확인한다. 낮은 신뢰도, 5초 이상 간격/처리 지연, 역행, 정지 프레임, 게임 시간 연결 해제는 반영하지 않는다.
- 관측한 재생성 시각까지 캠프 전체를 지도·추천·크레딧 합계에서 제외한다. 정확한 과거 처치 시각을 역산하여 만들지 않는다. 타이머 관측은 현재 페이지 메모리에만 유지하며 공유 링크에는 넣지 않는다.
- 사용자 확대샷 `106s`는 번들 OCR에서 `406s`/신뢰도 28로 잘못 읽혀 자동 반영 기준(75)에 미달했다. 이 정지 샷만으로 실게임 정확도를 주장하지 않는다.
- 로컬 Node 테스트 21개 파일 및 DOM 통합 테스트 통과: 캠프 전체 3마리 제외/재생성 경계/중복 방지/시간 역행/화면 정지/공유 종료. 실제 연속 게임 영상에서의 정확도는 미검증.

- 추가 사용자 확인: 일반 닭·들개·멧돼지·박쥐는 타이머가 없다. 고정 변이체 캠프에는 타이머가 표시된다. 자동 인식 선택 목록에서 일반 4종과 미확인 공격 드론을 제외한다. 일반 늑대·곰도 이번 자동 인식 대상에서는 제외한다. 자동 인식은 고정 변이체 16개 캠프에만 허용한다. 타이머 부재를 생존/처치의 근거로 쓰지 않는다. 타이머 없는 캠프는 수동 전체 처치와 기존 재생성 규칙을 사용한다.

## 일반 동물 수동 보정과 인식 범위 확정

- 일반 동물 아이콘을 선택하면 지역 목표 카드가 열리며 `캠프 전체 처치 기록`으로 선택한 게임 시각을 기록한다. 기존 재생성 규칙으로 지도·추천·크레딧에 반영하고 공유 링크로 복원할 수 있다.
- 한 마리만 처치했을 때는 전체 처치를 기록하지 않도록 명시한다. 부분 처치의 개체별 시간표와 실제 동물 사망 영상 인식은 아직 제공하지 않는다.
- 생성/재생성 예정은 `현재 상태 미확인`으로 표시한다. 화면에서 동물이나 타이머가 사라져도 처치를 만들지 않는다.
- 자동 타이머 입력은 고정 변이체만 허용하며 최초 생성 전 관측과 재생성 주기를 초과한 숫자는 거부한다.
- 사용자가 사냥 시점 또는 시간 프리셋을 바꾸면 화면 시간 연결과 타이머 인식을 중단하고 재확인을 요구한다.
- 로컬 JavaScript 21개 테스트 파일 및 jsdom 화면 생명주기 검증 통과. 브라우저/배포 결과는 해당 PR의 Checks와 Render 배포 기록을 참조한다.
- 화면 처리는 브라우저 내에서 수행하므로 Supabase 스키마나 운영 데이터 변경은 필요하지 않다.

- 배포 방식: 대용량 OCR 두 파일은 `scripts/PrepareOcr.java`에서 고정 버전과 SHA-256으로 검증해 빌드에 포함한다. 브라우저는 배포된 동일 출처 파일만 읽으며 언어 모델은 원본 `eng.traineddata`를 사용한다.
