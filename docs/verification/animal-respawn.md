# 야생동물 처치·재생성 검증 (#7)

기준 코드: main 72ad8a5. 구현 규칙 ID: `squad-12.0-fixed-20260915`.

## 구현한 동작

- `erHuntPhases`의 날짜/낮밤 길이와 카운트다운을 누적 게임 초로 변환한다. 시계 입력은 각 페이즈 길이로 제한한다. 8일차는 최종 낮만 제공한다.
- 캠프의 `events`에 `{at, kind, variant}`를 저장한다. `at`은 벽시계나 서버 시간이 아닌 선택한 게임 시점이다. `kind`는 `kill`이며 종류는 캠프 데이터로 결정한다.
- 닭 120초, 박쥐 150초, 멧돼지 130초, 들개 140초, 공격 드론 210초: 최초 생성 시간이 아니라 기록한 처치 시각부터 대기한다.
- 늑대는 처치 이후 다음 낮 시작, 곰은 다음 밤 시작에 재생성한다. 생성 정각에 처치하면 그다음 주기를 기다린다.
- `erHuntState`가 지도·동선·추천의 공통 판정이다. 재생성 전 목표는 제외하고 보상을 더하지 않는다. 한 추천 안에서 동일 캠프는 한 번만 포함한다. 추천은 선택한 시점의 스냅샷이며 이동 중 미래 재생성을 예약하지 않는다.
- 시간을 앞뒤로 이동해도 기록은 보존한다. 과거에 처치를 새로 입력하면 그 캠프의 이후 기록은 교체한다. 화면에 이 동작을 안내한다.
- `현재 시점 처치`는 캠프 전체 처치다. 부분 처치, 처치에 걸리는 시간, 다른 플레이어의 행동은 자동 추적하지 않는다.
- `계속 제외`는 재생성과 무관한 수동 제외다. 전체 처치 기록 초기화도 이를 해제하지 않는다. 이전 v1/v2 링크의 `cleared`는 시각을 알 수 없으므로 계속 제외로 보존한다.
- v3 공유 링크는 시계 버전과 모든 캠프 기록을 저장한다. 잘못된 이벤트·미생성 처치·지원하지 않는 종류를 검증하고 다른 시간표 버전의 기록은 거부한다.

## 변이체 배치의 의미

사용자 요청에 따라 확정 스폰 구역만 별도 캠프 데이터로 등록한다. 일반 캠프 163개와 확정 변이체 캠프 16개를 구분하며, ID는 `Mutant:종류:번호`다. 랜덤 변이·자색 안개·잠식 둥지의 수동 지정은 제공하지 않는다. 구버전 링크의 임의 변이 지정도 일반 캠프를 변이체로 바꾸지 않는다.

| 확정 변이체 | 캠프 수 | 기본 마릿수/캠프 | 최초 생성 | 처치 후 재생성 |
| --- | ---: | ---: | --- | ---: |
| 닭 | 3 | 6 | 1일차 밤 시작 (140초) | 180초 |
| 멧돼지 | 4 | 3 | 1일차 밤 시작 (140초) | 180초 |
| 들개 | 4 | 4 | 1일차 밤 시작 (140초) | 180초 |
| 늑대 | 2 | 3 | 2일차 낮 시작 (250초) | 210초 |
| 곰 | 3 | 2 | 2일차 밤 시작 (390초) | 240초 |

처치 기록이 없으면 생성 이후 유지하며 재생성 후에도 확정 변이체다. 일반 늑대·곰의 이전 시간대 생존 가정은 변이체에 적용하지 않는다. 참고 지도의 날짜 버튼은 종류 표시 프리셋이므로 실제 처치 후 타이머로 해석하지 않았다. 좌표는 지도 이미지에서 판독한 근사 위치다.
