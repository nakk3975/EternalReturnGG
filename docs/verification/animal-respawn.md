# 야생동물 처치·재생성 검증 (#7)

기준 코드: main 72ad8a5. 구현 규칙 ID: `squad-12.0`.

## 구현한 동작

- `erHuntPhases`의 날짜/낮밤 길이와 카운트다운을 누적 게임 초로 변환한다. 시계 입력은 각 페이즈 길이로 제한한다. 8일차는 최종 낮만 제공한다.
- 캠프의 `events`에 `{at, kind, variant}`를 저장한다. `at`은 벽시계나 서버 시간이 아닌 선택한 게임 시점이다. `kind`는 `kill` 또는 `variant`다.
- 닭 120초, 박쥐 150초, 멧돼지 130초, 들개 140초, 공격 드론 210초: 최초 생성 시간이 아니라 기록한 처치 시각부터 대기한다.
- 늑대는 처치 이후 다음 낮 시작, 곰은 다음 밤 시작에 재생성한다. 생성 정각에 처치하면 그다음 주기를 기다린다.
- `erHuntState`가 지도·동선·추천의 공통 판정이다. 재생성 전 목표는 제외하고 보상을 더하지 않는다. 한 추천 안에서 동일 캠프는 한 번만 포함한다. 추천은 선택한 시점의 스냅샷이며 이동 중 미래 재생성을 예약하지 않는다.
- 시간을 앞뒤로 이동해도 기록은 보존한다. 과거에 처치/종류를 새로 입력하면 그 캠프의 이후 기록은 교체한다. 화면에 이 동작을 안내한다.
- `현재 시점 처치`는 캠프 전체 처치다. 부분 처치, 처치에 걸리는 시간, 다른 플레이어의 행동은 자동 추적하지 않는다.
- `계속 제외`는 재생성과 무관한 수동 제외다. 전체 처치 기록 초기화도 이를 해제하지 않는다. 이전 v1/v2 링크의 `cleared`는 시각을 알 수 없으므로 계속 제외로 보존한다.
- v3 공유 링크는 시계 버전, 날씨, 모든 캠프 기록을 저장한다. 잘못된 이벤트·미생성 처치·지원하지 않는 종류를 검증하고 다른 시간표 버전의 기록은 거부한다.

## 변이체 배치의 의미

일반 날씨는 첫 재생성이 가능한 시점부터, 자색 안개는 최초 생성부터 변이체 관찰을 입력할 수 있다. 변이체가 무조건 등장한다고 추정하지 않는다. 처치 후 다음 개체는 변이 미확인 상태(일반 크레딧 기준)로 표시한다. 이전 늑대/곰을 처치했다고 가정하는 모드에서는 다음 생성 주기로 관찰을 이월하지 않는다.

잠식 변이체 선택은 **2일차 이후 실제 활성화한 안개 둥지의 출현 확인**이다. 일반 동물의 낮밤 필터를 적용하지 않으며, 처치 후 정상 캠프의 주기로 다시 생성하지 않는다. 나중에 실제로 다른 둥지가 활성화되었다면 해당 시점에서 다시 관찰을 입력할 수 있다. 특정 캠프가 안개 안에 들어가는지, 정확히 언제 안개가 생기는지는 추정하지 않는다.
