# ERGG Overlay 0.1.1 — Windows x64

설치 없이 실행하는 실험용 Windows 오버레이입니다. 압축을 풀고 `ERGG-Overlay-0.1.1-Windows-x64.exe`를 실행하세요. 코드 서명은 되어 있지 않습니다. 배포 출처와 파일을 확인하고, 조직이나 게임의 실행 제한을 우회하지 마세요.

## 사용

1. 게임을 테두리 없는 창모드로 실행합니다. 설정 창에서 팀원 닉네임을 쉼표로 구분해 입력하고 조회합니다. 팀원 자동 인식과 실시간 HP 등은 제공하지 않습니다.
2. 현재 일차·낮밤·남은 초를 입력해 적용합니다. 수동 시계 시작으로 시간을 진행시키거나, 화면의 게임 시계를 OCR로 연결합니다.
3. 지역 또는 작은 지도에서 출발점을 선택하고 동선 추천을 누릅니다. 선택한 동물 필터가 적용됩니다. 선은 방문 순서이며 벽을 고려한 길찾기가 아닙니다.
4. 일반 동물은 캠프를 선택하고 **전체가 처치된 경우에만** 기록합니다. 타이머는 기록 시각 기준 예상입니다.
5. 화면 연결을 사용하려면 게임 창 목록 새로고침 → 창 선택 → `게임 화면 공유`를 누릅니다. 공유 화면의 지도 영역·3쌍 지형 기준점·내 아이콘·시간을 설정하세요. 고정 변이체 타이머는 대상 캠프 및 숫자·아이콘을 별도로 지정합니다. 동시에 한 캠프만 추적합니다.
6. 설정 창을 닫으면 트레이에 남고 분석을 계속합니다. 종료는 설정 창의 앱 종료 또는 트레이 메뉴에서 합니다.

| 단축키 | 기능 |
| --- | --- |
| Ctrl+Shift+F8 | 오버레이 표시/숨기기 |
| Ctrl+Shift+F9 | 클릭 통과 ↔ 이동·크기 편집 |
| Ctrl+Shift+F10 | 설정 창 열기 |

기본은 클릭 통과입니다. 편집 모드에서는 헤더를 잡아 이동하고 창 가장자리로 크기를 바꿉니다. 설정에서 투명도와 위치 초기화를 지원합니다. 단축키 충돌 시 트레이 메뉴를 사용하세요.

## 범위와 검증

- 지도·시간·재생성 계산 및 화면 OCR는 로컬에서 실행합니다. 팀 랭크 조회만 기존 ER.GG 서버의 공개 조회 API를 사용합니다. API 키를 앱에 넣지 않습니다.
- 게임 메모리·패킷을 읽거나 게임에 주입하지 않습니다. 독점 전체화면 호환성 및 게임 정책상 허용 여부를 보증하지 않습니다.
- 시야 밖 생존·일반 동물의 죽는 동작은 자동 판정하지 않습니다. 생성/재생성 상태와 추천은 예상입니다.
- 이번 경기는 메모리에만 유지됩니다. 앱 재실행 또는 새 경기 버튼을 누르면 처치 기록과 화면 보정을 다시 설정해야 합니다.
- 자동 테스트: 경로/입력 제한, 설정 화면·동선·수동 처치·초기화·팀 조회, Windows 패키지 실행 및 창 편집 모드. 실제 Windows 게임 위의 가림·전체화면·캡처·단축키 충돌은 사용자 환경에서 확인해야 합니다.

## 개발 / 빌드

JDK 17+ 및 Node.js 22 필요. 저장소 루트에서 `java scripts/PrepareOcr.java`, 이후 desktop에서 `npm install`, `npm start`를 실행합니다. Windows 실행 파일은 `npm run dist:win`으로 만듭니다. GitHub Actions의 Windows overlay 워크플로가 실행 파일을 artifact로 제공합니다.
